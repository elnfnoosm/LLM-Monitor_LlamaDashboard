本地大模型监控台LLM Monitor · 使用说明（LlamaDashboard 改造版）
==================================================

【这是什么】
一个看本地大模型运行状态的小窗口：模型名称、模型在不在跑、现在是读题还是生成、
生成速度（每秒多少字）、当日累计token、历史人物、显存/CPU/内存占用以及查看模型运行log等等。只监控，停模型/换模型等控制功能暂不开放。
支持自动识别 Strata（serve\server.py）和 llama.cpp（llama-server 等），
启动谁就监控谁，不用改任何配置。


【怎么启动】（顺序不能反）
1. 先启动你的模型服务，例如：
   · Strata：双击 D:\Strata\Strata-main\run-iq3_s.bat
     （run-iq2_xs.bat 等其他配置也行，会自动识别）
   · LM studio、llama.cpp等：用你平时启动 llama-server 的脚本即可
2. 等模型启动好后，双击本文件夹里的：启动监控.bat
3. 几秒后窗口里出现模型名和数据，就是挂上了。

【按键】
q  退出监控（只是关掉监控窗口，模型继续跑，不受影响）
l  查看模型服务的运行日志（再按 l 或 Esc 返回；配置脚本启动、Strata、
   LM Studio 三种方式都能看，LM Studio 重启换了新日志文件也会自动跟上）
h  硬件详情：展开 GPU 频率、显存温度/热点温度等（再按 h 收起；只在硬件框内
   多几行字，框的宽度和三个框的排列方式都不会变）

【面板上主要看什么】
状态：reading = 正在读你的提问；generating = 正在生成回答；idle = 待机
速度：tok/s = 每秒生成的字数
顶部标题行：模型名、ctx（记忆容量）、运行时长、build（引擎版本）、[attach]（只监控不控制）
硬件框（左上）：
  左半看显卡：显存占用、带宽、功率、GPU 温度和风扇
  右半看整机：CPU 型号、CPU 使用率、内存使用率（已用/总量 GB）
  数字颜色：绿色 = 宽松，黄色 = 偏高，红色 = 接近满载
历史：下面的小字是最近 1000 条问答的结算记录
      Strata、配置脚本启动的 llama.cpp、LM Studio 三种方式都会自动读取各自的
      服务器日志；用 LM Studio 时，打开监控后历史区会直接带上今天已有的问答
累计（累计请求/累计输入/累计生成）：按"当前这个模型本次运行"统计——
      从日志里最后一次加载模型算起，跨天、日志分卷都连续累计；在 LM Studio
      里换另一个模型后自动从 0 重新开始。数字以服务器日志为准，关闭监控窗口
      甚至关电脑都不会丢（监控没开时发的请求，下次打开也会补上）
布局：所有框都会随终端窗口宽度自动伸缩，拖动窗口边缘调整大小即可
      （窗口宽于约 110 个字符时三个上框左右并排；窄于这个宽度就自动上下排列。
       是否并排只取决于窗口宽度：框里所有数字都定宽显示，待机、加载模型、
       生成回答时三个框的总宽度始终一样，不会因为数字变大变小而跳上跳下；
       硬件框里"内存"的容量数字会一直保留到显卡名和 CPU 名快碰上时才隐藏，
       再窄会缩短进度条；两个硬件名字始终同一行，宁可被边框裁掉也不换行）

【文件夹里都有什么】
启动监控.bat                                  平时只用这一个：双击启动监控
运行本文件安装环境（以后双击启动监控）.bat      第一次用/换电脑时：双击一次自动装好运行环境
README.md                                    更详细的图文说明（GitHub 项目主页显示的就是它）
app\                                         程序本体（源码 + Python 运行环境 .venv），不用管


【分享给别人】
方法一（推荐）：让对方到 GitHub 项目页面，点绿色的 “Code” 按钮 →
               “Download ZIP”，解压后按下面【新电脑第一次使用】操作即可，不用删任何东西。
方法二：直接把整个文件夹拷给对方（U盘、压缩包均可），拷贝前先删除
        app 里面的 .venv 文件夹（本机专用的运行环境，删了不影响任何东西）。

【新电脑第一次使用】
1. 先装好 Python 3.12 或更高版本
   （安装时务必勾选 Add python.exe to PATH；下载 https://www.python.org/downloads/）
2. 双击 “运行本文件安装环境（以后双击启动监控）.bat”，等它自动装完
3. 以后双击 “启动监控.bat” 即可使用

【常见情况】
· 窗口显示找不到服务：先确认模型服务是否已启动。
  （Strata 默认端口 8080；端口换了也没关系，程序会自动读取配置）
· 换了模型配置（iq2_xs 等）不用改任何东西，监控会自动发现。
· 整个文件夹可以随意移动/改名，启动 bat 用的是相对路径，不受影响。
